# 🛒 Full-Stack E-Commerce Website

## 🚀 Overview
This is a **MERN stack** e-commerce website where users can browse products, add items to their cart, place orders, and make secure payments. Admins can manage inventory, users, and orders.

## 📌 Features
### ✅ **User Features**
- 🔹 User authentication (JWT)
- 🔹 Browse & search products
- 🔹 Add to cart
- 🔹 Checkout with address selection
- 🔹 Payment integration (Stripe/Razorpay)
- 🔹 Order tracking & history

### 🔧 **Admin Features**
- 🛠️ Manage products (CRUD)
- 🛠️ Manage users (CRUD)
- 🛠️ Manage orders & deliveries
- 🛠️ Dashboard for analytics

---

## 🏗️ Tech Stack
| Technology  | Description |
|-------------|------------|
| **Frontend** | React.js, Tailwind CSS |
| **Backend**  | Node.js, Express.js |
| **Database** | MongoDB (Mongoose ORM) |
| **Auth**     | JWT, bcrypt.js |
| **Payments** | Stripe / Razorpay |
| **State Mgmt** | Redux Toolkit |
